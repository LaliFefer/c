# קופה רושמת — Cashier Pro

פרויקט C# בלמידת ארכיטקטורת השכבות, קופה רושמת לחנות עם ממשק ניהול וממשק קופה.

## תיאור כללי

זוהי מערכת קופה רושמת עבור חנות, הכוללת:
- בחירת סוג חנות וקטגוריות מוצר מותאמות
- ממשק מנהל לחיבור, ניהול מוצרים ומבצעים
- ממשק קופה לעריכת חשבונות, בחירת לקוחות וניהול הזמנות
- תמיכה בלקוחות מועדון עם הטבות
- שמירת נתונים באמצעות שכבות נתונים ופיצול ל-DAL / BL / UI

## מטרות הפרויקט

הפרויקט בוצע בהתאם לדרישות קורסיות של ארכיטקטורת שכבות, ומכסה את השלבים הבאים:
1. שכבת נתונים (DAL) עם ישויות Product, Sale ו-Customer
2. מימוש שירותי גישה לנתונים ב-C# באמצעות ממשקים ו-LINQ
3. שמירת נתונים ב-XML כמימוש נוסף של DAL
4. בניית שכבה לוגית (BL) עם חוזי שירות, Singleton ו-Simple Factory
5. ממשק גרפי (WinForms) למנהל ולקופאי

## ישויות נתונים מרכזיות

### מוצר
- מספר מזהה ייחודי (ID)
- שם מוצר
- קטגוריה (enum)
- מחיר
- כמות במלאי

### לקוח
- תעודת זהות
- שם
- כתובת
- טלפון
- מצב מועדון

### מבצע
- מזהה ייחודי
- מזהה מוצר
- כמות נדרשת לקבלת מבצע
- מחיר כולל במבצע
- האם מיועד ללקוחות מועדון או לכלל הלקוחות
- תאריך התחלה
- תאריך סיום

## קטגוריות מוצרים

נושא הפרויקט מאפשר בחירת חנות ודוגמאות קטגוריות, לדוגמה:
- חנות נעליים: MEN, WOMEN, KIDS, SPORTS, ELEGANT
- חנות בגדים: חולצות, שמלות, מכנסיים, גרביים, פיג'מות

## פונקציות מנהל

המנהל יכול:
- לצפות ברשימת המוצרים
- להוסיף מוצר חדש
- לעדכן מוצר קיים (שם, מחיר, כמות, קטגוריה)
- לקבל התראות על מלאי נמוך
- להזמין מלאי חדש ולהגדיל את המלאי
- לצפות ברשימת מבצעים
- להוסיף מבצע חדש
- לעדכן או למחוק מבצע קיים

## פונקציות קופאי

הקופאי יכול:
- לצפות בקטלוג מוצרים
- לבצע חשבונות לקוח רגיל או לקוח מועדון
- להוסיף לקוח למועדון
- לעדכן פרטי לקוח
- להסיר לקוח מהמועדון

## ארכיטקטורה ושכבות

הפרויקט מחולק לשכבות:
- `DalApi` / `DalFacade` — חוזי שיטות גישה לנתונים
- `DalList` — מימוש נתונים בזיכרון באמצעות רשימות / DataSource
- `DalXml` — מימוש נתונים שמירה וטעינה מ-XML
- `BL` — שכבה לוגית וממשקי פעולה לעסקים
- `UI` — ממשק משתמש גרפי ב-WinForms
- `Tools` — כלים נלווים וסיוע
- `BlTest` / `DalTest` — תוכניות בדיקה לשכבות השונות

## טכנולוגיות

- C#
- .NET 9.0 (WinForms)
- WinForms ל־UI
- LINQ לעיבוד נתונים
- XML לשמירת פריטים
- מחלקות לוגיות וטכניקות Singleton / Factory
